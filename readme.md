# Café POS Lite

A simple café point-of-sale web application built with
HTML, CSS, and Vanilla JavaScript.

## Features

- Product listing
- Search
- Category filter
- Shopping cart
- Quantity management
- Price calculation
- Checkout
- API integration
- Loading & error handling

## Tech Stack

- HTML
- CSS
- JavaScript
- REST API

## Concepts

- Array methods
- Objects
- DOM manipulation
- Event handling
- Async/Await
- Fetch API
- Error handling

## How to Run

1. Clone repository
2. Open index.html
3. Run with Live Server
